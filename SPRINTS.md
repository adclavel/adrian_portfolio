# Sprint Log

This document tracks my weekly development sprints for my portfolio website.  
Each sprint runs from **Sunday to Saturday**, with code pushed at the end of the week.

The goal of this sprint-based workflow is to:

- Break development into focused, achievable goals
- Maintain consistent progress and clean version control
- Simulate real-world agile practices used in software teams

Each sprint includes a clear goal, completed work, and planned improvements for the next sprint.
